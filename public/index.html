            É o telefone por onde os pacientes falam com a Serena. Quando a Evolution API está
            configurada, é ela quem entrega as mensagens — o gateway do OpenClaw abaixo só entra
            como reserva, se a Evolution falhar ou não estiver configurada. A sessão do gateway cai
            de vez em quando — troca de aparelho, celular desligado por dias. Este cartão mostra o
            estado dos dois; reconectar o gateway é um comando no servidor, e o botão explica qual.
